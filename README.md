# MyPortfolio

Source for [davidedwards.dev](https://davidedwards.dev), a static single-page site built with [Astro](https://astro.build).

```bash
npm install
npm run dev      # local dev server at http://localhost:4321
npm run build    # static output in dist/
```

Content (experience, projects, links) lives in `src/data/site.ts`.
